# Potato Economy

Potato Economy is a Minecraft plugin designed to enhance your server with a comprehensive economy system. It includes virtual currency, player-to-player trading, dynamic pricing, boss progression, dimension unlocking, special powers, and automated welcome messages. This plugin is perfect for servers looking to add depth and engagement to their gameplay.

## Install

1. Download the plugin JAR file from the GitHub releases page.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your server to load the plugin.

## Use

1. **Sell Items**: Use the `/sell` command to sell items you are holding.
2. **Set Prices**: Use the `/price <item> <price>` command to set the price of an item and announce it in the market.
3. **View Market**: Use the `/market` command to view all advertised items, their prices, and sellers.
4. **Trade**: Use the `/trade <player> <item> <amount>` command to initiate a trade with another player.
5. **View Powers**: Use the `/powers` command to view and activate special powers.
6. **Unlock Dimensions**: Use the `/unlock <dimension>` command to unlock new dimensions.
7. **View Boss Progression**: Use the `/boss` command to view your boss progression.
